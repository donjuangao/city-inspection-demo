# 城市设施智能巡检 · 交互原型(演示用)

> **全站虚构声明**:本仓库是一份**面试/评审用的交互原型**。其中出现的城市、机构、设施编号、传感器、班组、工单、线索、告警、时间与全部数字,**均为虚构的演示数据**,不代表任何真实机构的现状、系统或数据。
> **零真实照片**:所有「证据图」都是代码现场生成的 **inline SVG 矢量示意**,统一带「AI 生成示意」角标。仓库内不含任何照片、外部图片或第三方素材。
> **人物一律为岗位角色**(区复核员 / 复核主管 / 区值班长 / 区巡检管理者 / DMT / 班组),无真人姓名。
> 页面中出现的 SLA、阈值、置信度、覆盖率等数字**全部是设计假设值**,在界面上以「假设值」提示标注。

## 这是什么

一个**纯静态、零依赖、零后端**的单页原型,演示「AI 看见 → 机械规则验实 → 人定性 → 全程留痕」这条链路在三条业务线上的实际走法:

- **排水/井盖线(应急流)**:传感器报警 → 双闸校验 → 紧急快车道自动派单 + 只读预警广播 → 人 15 分钟并行复核(可撤回召回)→ 班组处置 → AI 复验 → 人裁闭环。
- **路面线(养护流)**:移动传感网批量入池 → 五项机械校验 → 自动升格(免人工)→ 周批养护工单;低置信件走批量半审,可存疑归档。
- **灌溉管网线(预警调查流)**:水量平衡规则报警 → AI 时序判型 → 自动开调查案 → 人立案 → 现场核查 → 流量回归 → 人结案。

核心立场:**定性权(线索→告警的签字)永远在人**;自动化产出的是工单与建议,不是告警。**每一次自动处置也记一条动作日志**——机械不豁免审计。

## 怎么跑

纯静态文件,无需构建、无需安装:

```
# 方式一:本地起个静态服务器
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/app.html

# 方式二:直接双击 app.html 用浏览器打开(file:// 亦可运行)
```

| 入口 | 说明 |
|---|---|
| `app.html` | Web 工作台(桌面):左侧六模块导航 + 顶栏假时钟 |
| `crew.html` | 班组处置端(手机竖屏 390px) |
| `public.html` | 公众上报轻端(手机竖屏 390px) |
| `index.html` | user story 导航页(建造中) |

**怎么看**:顶栏点「▶ 推进剧情」,按「Al Ain 暴雨前夜」的场景时刻表从 19:02 走到 21:30(共 12 步);每步弹一行叙事,页面上的数字、队列、班组状态、动作日志随之变化。点错了或想重来,点「重置演示」回到开场。

## 演示范围(诚实边界)

- **时间是假时钟**:不是真实时钟,只在「推进剧情」时步进。SLA 倒计时按场景步进变化,不按现实秒走。
- **没有后端**:全部数据 mock 在前端 store(sessionStorage),刷新保留场景态;不调用任何 API,不发出任何网络请求。
- **外围模块交互浅**:统计总览 / 设施台账 / 系统管理成型可点,但深度低于核心链路页。
- **场景覆盖**:核心场景按时刻表逐步可走;少数场景以静态形态(详情页信息行 / 横幅)呈现,导航页「本原型演示范围」会逐条列出,不静默缺席。

## 目录结构

```

assets/data.js    全部 mock 数据 + 场景时刻表 T1-T12
assets/ui.js      共享组件(对象卡 / 动作面板 / 时间线 / 校验卡 / 横幅 / 证据示意 SVG)
```

## 控制台可自测(开发者)

```js
S.now()                      // 假时钟当前值
S.nextStep()                 // 推进一步剧情(连按 12 次走完 T1→T12)
S.get().actionLog.length     // 动作日志条数(走完 12 步应 ≥25)
S.check('confirm',{clueId:'CL-0417'})   // 只读校验:动作能不能提交、不满足哪一条
S.commit('confirm',{clueId:'CL-0417'})  // 唯一状态变更入口(会追加一条动作日志)
S.reset()                    // 回到 T0
```

## 技术与合规

- 无 npm / 无构建 / 无 CDN / 无外链字体 / 无外部图片;系统字体栈;GitHub Pages 直接可跑。
- 界面全中文;浅色政务风,状态色语义:高危应急=红 / 待核查=灰 / 已确认闭环=绿 / 进行中信息=蓝 / 预警降级=琥珀。
- 地址口径为「设施编号 + 街区名 + Al Ain」(市政台账以设施编号定位,界面不显示街道字段)。街区名与地标取自 Al Ain 的真实公开地名,仅作演示语境,不指代任何真实设施。
