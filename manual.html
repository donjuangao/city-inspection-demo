城市设施智能巡检 demo · 演示手册

这份手册回答三个问题:每一幕看什么、去哪个界面看、走到下一幕系统里到底变了哪个卡/横幅/数字。内容逐条取自 assets/data.js(场景时刻表),口播与预判追问原文收录于各幕卡。

这场演示怎么开始

  1. 打开哪个文件都行:index.html 是叙事导览页(六幕结构,内嵌真实机器截面),从头读到尾就是一遍完整讲解;app.html 是工作台实机本体,打开就能直接点底部导览条「▶ 下一镜」把整场戏走一遍。两者是同一份状态的两个入口,不冲突,挑一个顺手的开始。
  2. 认识两件东西:顶栏「系统时刻」是工作时钟——初始 19:00,只在导览推进时才往前跳,不按现实秒走;底部是分镜导览条,「▶ 下一镜」每点一次推进一镜,页面自动跳到该镜要看的位置并高亮焦点;「重置数据」把状态清空、回到 19:00 的 T0 初态。
  3. 两端共享同一份状态:工作台 app.html、班组处置端 crew.html,两个页面在同一个浏览器标签页里共享同一份进度;任一处点「重置数据」,两端一起回到 T0 · 19:00。

导览怎么走 · 主线 20 镜 + 6 条支线

共 39 镜
① 主线:一路点「▶ 下一镜」

主线 20 镜按三条业务线的次序排:序幕(第 1 镜)→ 井盖线(2-9)→ 异常对照(10-11)→ 路面线(12-13)→ 管网线(14-15)→ 越级与压力(16-19)→ 终幕日志(20)。这 20 镜与下面 T0-T12 的幕卡一一对应:第 1 镜 = T0,第 2-4 镜 = T1,第 5 镜 = T2,第 6-8 镜 = T3(班组段拆三镜:接单 / 到场+前照 / 后照+完工,浮窗逐镜跟着走一格),第 9 镜 = T4,第 10 镜 = T5,第 11 镜 = T6,第 12-13 镜 = T7,第 14-15 镜 = T8,第 16 镜 = T9,第 17 镜 = T10,第 18 镜 = T11,第 19 镜 = T12,第 20 镜 = 终幕。想细看某一幕发生了什么、去哪看、变化焦点在哪,翻到对应的 T 卡。

每镜自动切角色:每一镜都声明了它该由谁来看,进镜自动把顶栏身份切到该镜的视角——主管落锤的镜(驳回 / 对账裁定 / 抽审 / 提级 / 参数变更 / 抢占仲裁 / 兜底件)切「复核主管」,其余为「区复核员」。导览条上「当前视角」徽章显示的是此刻的真实身份;下车后你自己切过的身份,导览不会改回来。

①之附 章节抽屉:跳镜的唯一入口(R89 改)

导览条上不再平摊分镜点列,只报「第 n/N 镜」加一条细进度条。要跳镜点导览条上的「☰ 章节」:右侧滑出一张 360px 宽的抽屉(不半屏),按章分组列出全部 39 镜 —— 序幕 / 井盖线 / 异常支线 / 路面线 / 管网线 / 越级与压力 / 终幕,章序就是「▶ 下一镜」实际走的次序;支线镜缩进一级挂在它的分岔点下面,标着「支线『X』第 k/m 步」。当前镜高亮、走过的镜淡色,点任意一行直接跳过去;Esc 或点抽屉外面关。手机浮窗与「流程位置 / 后端发生了什么」两枚浮层按钮仍在导览条上,位置不变。

② 支线:主线上带「↳ 深入…」按钮的镜是分岔点

六条支线是这场戏里「往下钻一层」的部分:进去逐镜走,走到尽头自动回主线,中途也可以点「↩ 回主线」。支线镜在章节抽屉里缩进挂在它的分岔点下面,可以直接点。管网支线的前三镜会在右侧弹一张实时数据卡(核查任务包 ×2 / 关阀试验流量对比),数据取自当前世界状态 —— 关阀试验那张卡上的读数就是班组在手机浮窗里一段一段填回来的;手机浮窗开着时数据卡自动让开一个浮窗宽度,两张卡并排不叠。点右上 × 收起。

③ 两枚浮层:随时问「我在哪」和「后台发生了什么」

流程位置 = 当前镜落在本条业务线流程图的哪个节点:图按线分四张(井盖 / 路面 / 管网 / 派单与调度),主干带分支(驳回支、设备工单支、升格支、抢占支、复验打回支),已走过的路径加深,分支节点上标着通道色和判据编号(如井盖图上「双传感器互证 MH-R01」那条边才通向机器直派);判据编号是蓝色下划线的,悬停出判据原文、点开出规则卡(参数当前值 / 基线值 / 版本 / 可改权),浮层底部还挂着一张「本线规则表」折叠区;方框可点的直接跳到对应分镜。后端发生了什么 = 这一镜落了哪些动作记录(谁、何时、对哪个对象、带什么参数、快照号),支线镜显示的是它自己那条动作链。

④ 手机浮窗:现场端那一屏

涉现场端的镜(班组接单、到场+前照、后照+完工、路面周批处置、管网关阀读数回传、管网转维修工单)会自动弹出右侧手机浮窗,里面就是 crew.html 本体,自动切到对应班组。它与工作台共用同一份状态:推进一镜,浮窗里的工单状态当场翻。浮窗可拖动、可关闭、可「新窗打开」;任何时候点导览条上的「📱 现场端」都能重新唤起。

⑤ 下车与回车

导览途中随便点侧栏、点卡片、切角色,都算「下车」——导览条会显示「已下车 · 回到第 N 镜」,状态不动,你可以自由操作;点一下就回到原来那一镜继续。往回跳镜或进支线时状态是重放出来的(重新播种后静默连推到位),所以同一镜任何时候点到,看到的都是同一份状态。
